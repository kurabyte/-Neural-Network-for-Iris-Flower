# Neural Network for Iris Flower Classification

## 📌 Project Overview
This project implements a Neural Network from scratch by using Scikit-Learn to classify the famous Iris flower dataset into three species: Setosa, Versicolor, and Virginica.

## 🛠️ Technologies Used
- Python 3
- Pandas, NumPy (for Data Manipulation)
- Scikit-Learn/TensorFlow/Keras (for Model Building)

## 📊 Dataset
The dataset contains 150 samples of Iris flowers with 4 features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## ⚙️ How it Works
1. Data is loaded and preprocessed.
2. Exploratory Data Analysis (EDA) is performed to visualize the features.
3. A Neural Network is built with 2 hidden layers.
4. The model is trained on 80% of the data and tested on 20%.
5. Accuracy is calculated, and a confusion matrix is plotted.

## 🚀 How to Run
1. Clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Run all cells.

## 📈 Results
- Final Test Accuracy: 93.33%
- Loss Curve: Dropped smoothly from 1.09 to 0.74
